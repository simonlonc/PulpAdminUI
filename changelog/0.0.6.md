# 0.0.6

**Released:** 2026-09-19

### Added

- **Container images:** `Containerfile.debian`, `Containerfile.alpine` and `Containerfile.ubi` build the app on Debian 13, Alpine 3.24 and Red Hat UBI 9
- **Build script:** `containers/build.sh` builds and tags any or all of the three variants locally with `podman` or `docker`
- **Image publishing:** `.github/workflows/images.yml` builds all three variants and pushes them to GitHub Packages (`ghcr.io`)

### Changed

- **Runtime project name:** `PULP_PROJECT_NAME` is now read per request in the root layout instead of being inlined into the client bundle at build time, so one image serves any deployment
